# 素材来源

## 网站插画

`assets/workbench.webp`：通过内置 image_gen 生成设计概念，再从概念中提取工作台插画。透明背景，包含猫、终端、书、植物、掌机和杯子。仅作为个人站插画，不代表真实产品界面或设备。

提示词摘要：暖白、炭灰、杏桃、鼠尾草色的个人作品站；完整呈现介绍、精选作品和关于我。随后保留概念中的工作台插画，移除页面文字和产品行，生成透明背景独立素材。正式素材保持透明度，缩至 1000×667 并转为 WebP。

原始输出保留在用户本地 Codex generated_images 目录；完整提示词记录在本次 Codex 对话。网站不引用该机器路径。

`assets/cat.svg`：可编辑的小猫标记，与已确认的 GitHub 主页小猫方向保持一致。

## 作品配图

- `shouxia-home.webp`、`shouxia-code.webp`：来自 [收下公开素材](https://github.com/xiaomao361/shouxia/tree/main/docs/app-store/screenshots/sanitized-1.2.5)。它们是 AI 编辑的脱敏展示图，不是原始实机截图或最终商店截屏。页面明确标注。只缩放和转为 WebP，未重新生成产品界面。
- `dockshelf-mark.svg`：来自 [搁这儿品牌标记](https://github.com/xiaomao361/dockshelf/blob/main/docs/brand/DockShelfMark.svg)。保留原矢量源文件，不伪造应用截图。
- `radwater.webp`：来自 [Radwater 同源渲染图](https://github.com/xiaomao361/radwater/blob/main/assets/screens.png)。无损转为 WebP；网页媒体窗口展示图集左上角的水边场景，原图内容没有修改。不是设备照片。

以上项目与品牌属于 Zhou Wei。收下与搁这儿的公开源代码和品牌素材各自的许可边界仍以原仓库为准，本网站不对其重新授权。
