# 素材来源

## 网站插画

`assets/workbench.webp`：通过内置 image_gen 生成设计概念，再从概念中提取工作台插画。透明背景，包含猫、终端、书、植物、掌机和杯子。仅作为个人站插画，不代表真实产品界面或设备。

提示词摘要：暖白、炭灰、杏桃、鼠尾草色的个人作品站；完整呈现介绍、精选作品和关于我。随后保留概念中的工作台插画，移除页面文字和产品行，生成透明背景独立素材。正式素材保持透明度，缩至 1000×667 并转为 WebP。

原始输出保留在用户本地 Codex generated_images 目录；完整提示词记录在本次 Codex 对话。网站不引用该机器路径。

`assets/cat.svg`：可编辑的小猫标记，与已确认的 GitHub 主页小猫方向保持一致。
