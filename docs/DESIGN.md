# 设计与验收

## 已确认方向

个人作品主页与关于我。暖白、炭灰、少量杏桃色和小猫元素。展示六个真实作品，直接进入产品、下载或 GitHub。没有文章时不展示空博客入口。

## 设计系统

- 背景 `#f7f4ee`，文字 `#292d2a`，次要文字 `#62665e`，分隔线 `#d6d1c7`。
- 主按钮杏桃色 `#dfab8b`；文本链接使用更深的 `#965a38` 保证可读性。
- 中文标题使用本地宋体栈，英文品牌使用 Georgia；正文使用系统无衬线字体，无外部字体请求。
- 最大内容宽度 1120px。介绍两栏、作品图文行、工具文字列表、关于我与页脚。
- 760px 以下单栏；360px 以下进一步收紧导航。图片保留固有尺寸字段，明确焦点样式，减少动态效果时关闭平滑滚动与过渡。
- 所有导航和下载都是原生链接，网站无必需 JavaScript、账号、表单、统计或第三方脚本。

## 与生成概念的有意差异

1. 概念中 ClaraCore、Cora 的简介不准确；实现使用公开 README 核对后的事实。
2. 概念中收下、搁这儿和掌机界面是生成示意；实现使用已有脱敏展示图、原品牌标记和同源游戏渲染图。
3. 增加明确的 App Store、下载与 GitHub 入口，以及必要的素材性质说明。
4. 更深的文本链接色替代浅杏桃链接文字，以改善对比度。
5. 既定版式保留，不以生成图片作为网页或交互控件。

## 验证层级

已完成源文件与静态构建检查：本地素材存在、页面内部锚点完整、图片尺寸字段、标题与语言标记、SVG XML、HTTPS 链接，以及键盘焦点与减少动态效果的 CSS。

实际桌面、手机浏览器排版、键盘与触控体验仍待用户验收。本轮没有获得浏览器操作授权，因此未导航浏览器、截图或进行可视化交互走查。不能把静态构建检查称作视觉验收。

手动检查：在桌面与手机打开站点；查看标题、图片和导航是否完整；点「看看作品」与「关于」；分别打开下载链接；用 Tab 检查焦点可见。
