# 设计与验收

## 页面方向

个人作品主页与关于我。暖白、炭灰、少量杏桃色和小猫元素。四项精选作品、其他开发工具、三项制作中的实验。介绍直接描述用途，下载与源码入口分开，没有内容时不展示博客入口。

## 设计系统

- 背景 `#f7f4ee`，文字 `#292d2a`，次要文字 `#62665e`，分隔线 `#d6d1c7`。
- 主按钮杏桃色 `#dfab8b`；文本链接使用更深的 `#965a38` 保证可读性。
- 中文标题使用本地宋体栈，英文品牌使用 Georgia；正文使用系统无衬线字体，无外部字体请求。
- 最大内容宽度 1120px。介绍两栏、作品图文行、工具文字列表、关于我与页脚。
- 760px 以下单栏；360px 以下进一步收紧导航。图片保留固有尺寸字段，明确焦点样式，减少动态效果时关闭平滑滚动与过渡。
- 所有导航和下载都是原生链接，网站无必需 JavaScript、账号、表单、统计或第三方脚本。
- 制作中项目在桌面排列为三列，手机为单列。插画、品牌标记、界面示意和游戏预览各自说明用途。

## 内容维护

1. 首屏、metadata、图片说明、项目介绍与 GitHub README 使用同一组事实，去掉泛化宣传语和协作过程说明。
2. AI Passport 是设备名称，ClaraCore、DSH 的智能体与 MCP 是实际功能；不为回避词语而删掉这些必要含义。
3. 不将本地开发版、商店版与社区公开版混为一谈。制作中的项目不显示假下载按钮。
4. 不以版本号推测功能，以实际分发渠道和对应更新记录为依据。
5. 图片的生成、脱敏和软件渲染来源保留在 [素材记录](ASSETS.md)，公开页面只用必要的示意或预览标注。
